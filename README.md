# 星球充能站 Cosmic Clicker

一款霓虹太空风格的轻量点击放置游戏。点击能量核心、建设轨道设施，并通过超新星重启获得永久强化。

## 功能

- 点击收益与每秒自动收益
- 8 种可重复升级与 10 项成就
- 超新星重启和永久星尘倍率
- 最多 8 小时离线收益
- 浏览器本地存档、轻量合成音效与响应式布局

## 本地开发

```bash
npm install
npm run dev
```

测试和构建：

```bash
npm test
npm run build
```

## 发布

项目已配置 GitHub Actions。推送到 `main` 后，工作流会测试、构建并发布至 GitHub Pages。
